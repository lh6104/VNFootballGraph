📊 FILTERING ARCHITECTURE
================================================================================

┌─────────────────────────────────────────────────────────────────────┐
│                        MULTI-SIGNAL EVALUATION                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  1. File/Media Check (SKIP_PREFIXES)          → -5 points           │
│  2. Blacklist Check (NOISE_PAGE_TITLES)       → -4 points           │
│  3. Keyword Matching (INCLUDE vs EXCLUDE)     → ±3 points           │
│  4. Semantic Patterns (20+ regex)             → +3 points           │
│  5. Category Validation (12 valid categories) → +3 points           │
│  6. Infobox Validation (8 valid types)        → +3 points           │
│  7. Neighbor Quality (linked by core nodes)   → +1 point            │
│  8. Graph Distance (from seed node)           → -2 if too far       │
│  9. NER Entity Detection (optional)           → +2 points           │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
                                  ↓
┌─────────────────────────────────────────────────────────────────────┐
│                          LAYER ASSIGNMENT                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  Score ≥ 5  →  CORE     (Players, Coaches, Clubs)                   │
│                         ✅ Expand links, high priority               │
│                                                                      │
│  Score ≥ 2  →  CONTEXT  (Stadiums, Tournaments, History)            │
│                         📌 Keep but don't expand                     │
│                                                                      │
│  Score < 2  →  SKIP     (Geography, Politics, Media)                │
│                         ⛔ Discard immediately                        │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘

================================================================================
⚙️ CONFIGURATION TUNING GUIDE
================================================================================

To adjust filtering behavior, edit src/config.py:

1. Make filtering MORE STRICT (reduce noise):
   - Increase RELEVANCE_SCORE_THRESHOLD_CORE (e.g., 6 or 7)
   - Increase penalty weights (exclude_keyword_hit: -4 or -5)
   - Add more EXCLUDE_KEYWORDS

2. Make filtering MORE LENIENT (increase recall):
   - Decrease RELEVANCE_SCORE_THRESHOLD_CORE (e.g., 4)
   - Increase positive weights (keyword_match: 4 or 5)
   - Add more INCLUDE_KEYWORDS

3. Disable specific filters:
   Set ACTIVE_FILTERS[filter_name] = False

4. Add custom semantic patterns:
   Append to SEMANTIC_PATTERNS list
