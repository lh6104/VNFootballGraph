Usage Examples
===================================================

# Basic usage
python -m src.main

# Custom seed and depth
python -m src.main --seed "Văn Quyết" --depth 2

# JSON output only
python -m src.main --output json

# Full configuration
python -m src.main \
  --seed "Nguyễn Quang Hải (sinh 1997)" \
  --depth 2 \
  --output both \
  --neo4j-uri "bolt://localhost:7687" \
  --clear-db

# Run examples
python example.py

===================================================
Graph Schema
===================================================

Nodes:
- Player (name, birth_date, nationality, position, height, url)
- Coach (name, nationality, url)
- Club (name, league, stadium, founded, url)
- NationalTeam (name, url)

Relationships:
- PLAYED_FOR: Player → Club
- COACHED: Coach → Club
- TRAINED_UNDER: Player → Coach
- MEMBER_OF: Player → NationalTeam
- TEAMMATE_WITH: Player ↔ Player
